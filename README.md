# Perpeye Web (Next.js + TypeScript + Tailwind v3)

```bash
npm install
npm run dev      # http://localhost:3000
npm run build
```

- Design tokens (colors, fonts, widths): `tailwind.config.ts`
- Figma assets: `public/images`, `public/icons`, `public/fonts`
- Env: copy `.env.example` to `.env.local`
